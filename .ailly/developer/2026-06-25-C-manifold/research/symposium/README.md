# Symposium Agent Packet

This folder contains reusable materials for running the three-agent symposium
described in `../symposium-review-prep.md`.

## Background Briefs

- `agent-a-formal-methods-background.md`: opposed formal-methods and
  categorical-semantics reviewer.
- `agent-b-empirical-eval-background.md`: opposed empirical-evaluation and
  agent-reliability reviewer.
- `agent-c-systems-practitioner-background.md`: supportive agentic-workflow
  systems practitioner.

## Process Prompt

- `symposium-orchestration-prompt.md`: shared prompt describing the individual
  review phase, panel discussion phase, convergence rules, and final decision
  format.

## Intended Use

Give each reviewer the shared project materials, this folder, and their own
background brief. Run the individual reviews first without discussion. Then run
the discussion phase from `symposium-orchestration-prompt.md` to reconcile hard
gates, vetoes, scores, and continuation constraints.
