# CSV schema

Booleans are coded `true` or `false`. Empty cells are coded null, never a zero. Percentages and shares are in points (0 to 100) unless stated otherwise.

## Shared keys

These columns identify a race.

| Column | Meaning |
| --- | --- |
| `year` | Election year. The `candidates` and `races` files cover 2014 to 2026, and `baseline_` files cover 2008 to 2013 so every window race has a prior. |
| `state` | Two letter postal code. |
| `office` | `house`, `senate`, or `governor`. |
| `seat` | House district number (0 for at large), Senate class (1 to 3), or 0 for a governorship. |
| `special` | True for a special election to fill a seat outside its regular cycle. |
| `round` | Round of the vote: `general`, `runoff`, or `rcv_final` (final ranked choice round). |
| `source_id` | Id of a row in `data/sources.csv` naming where the row came from and when it was fetched. |

## data/overrides/ and data/sources.csv (hand maintained inputs)

### data/sources.csv

One row per source. Rewritten by `pull.py`, _removing unused sources_.

| Column | Meaning |
| --- | --- |
| `source_id` | Integer key. Never reused for a different source, so hand maintained files stay valid when a pull adds rows. |
| `name` | Dataset file, Wikipedia page and revision, or Ballotpedia page. The name `ap` marks AP live results. |
| `url` | Where to retrieve the source. |
| `fetched_at` | Date or UTC time the source was fetched or checked. |

### data/overrides/redistricting.csv

The first election year of each House map, used to set `redrawn` and to form the dummymander groups.

| Column | Meaning |
| --- | --- |
| `first_election_year` | First general election using that map. |
| `kind` | `census` for a map drawn after a census, or `mid_cycle` for a map changed within a decade. |

### data/overrides/result_overrides.csv

Results entered by hand. Rows for a race and round replace every pulled row for it, and rows for a round the sources lack are added. Shares and totals are computed from `votes`.

| Column | Meaning |
| --- | --- |
| `candidate` | Candidate name. Normalized on read, so any spelling is accepted. |
| `party` | `DEM`, `REP`, or `OTHER`. |
| `votes` | Votes the candidate received in this round. |
| `official` | True when the count is certified. |
| `source_id` | Source the row was entered from, usually a Wikipedia revision. Its `fetched_at` is the date the row was checked. |

## data/ (generated by pull.py)

`out/elections.duckdb` is a working database built from these files by `analyze.py`. It holds the same columns as tables, plus a `sources` table, and has no schema of its own.

### data/candidates.csv and data/baseline_candidates.csv

One row per candidate per round. `candidates.csv` holds 2014 to 2026, and `baseline_candidates.csv` holds 2008 to 2013.

| Column | Meaning |
| --- | --- |
| `candidate` | Candidate name in one normal form, `First Middle Last Suffix` in mixed case, whichever source wrote it. See Candidate names at the end. |
| `party` | `DEM`, `REP`, or `OTHER`. |
| `votes` | Votes received. Empty for an uncontested candidate the state never counted. |
| `total_votes` | All votes cast in this race and round. All `votes` from candidates in this round should sum to `total_votes`. |
| `pct` | `votes` as a share of `total_votes`. |
| `incumbent` | True when this candidate is a running incumbent of the race. |
| `official` | True when the count is certified. A 2026 AP row is not official until AP marks the race certified. |

### data/races.csv and data/baseline_races.csv

One row per race, built from the deciding round (a runoff or final ranked choice round when present, otherwise the general). `races.csv` includes the 2026 races, which change as counts are reported.

| Column | Meaning |
| --- | --- |
| `round` | Round that decided the race. |
| `dem_candidate`, `gop_candidate` | Top Democrat and top Republican. Empty when a party fielded no one. |
| `dem_votes`, `gop_votes` | Votes for those candidates. |
| `dem_pct`, `gop_pct` | Their shares of `total_votes`. |
| `other_votes` | Votes for everyone else. |
| `total_votes` | All votes in the deciding round. Empty with the counts when the race was uncontested and uncounted. |
| `winner_party` | Party of the leading candidate: `DEM`, `REP`, or `OTHER`. |
| `incumbent_name` | Running incumbent. |
| `incumbent_party` | Party of the incumbent. |
| `incumbent_running` | True when the incumbent is on the ballot. A Senate seats require two years of service to be marked incumbent. |
| `paired_incumbents` | House only. True when two incumbents ran for this seat after a redraw. |
| `redrawn` | House only. True when the race year is the state's first election on a new map, per `data/overrides/redistricting.csv`. |
| `official` | True when every deciding round row is certified. |

### data/turnout.csv

Statewide turnout from the University of Florida Election Lab, for each even year from 2008.

| Column | Meaning |
| --- | --- |
| `vep` | Voting eligible population. |
| `total_ballots` | Total ballots counted. Empty when the Lab reports none. |
| `official` | False for the Lab's own estimates made before states certify. |

### data/presidential_lean.csv

Partisan lean of each state for each year, from the latest presidential election before that year.

| Column | Meaning |
| --- | --- |
| `state` | State. |
| `year` | Year the lean applies to. |
| `president_year` | Presidential election the lean comes from. |
| `margin` | Democratic minus Republican share of all presidential votes, in points. |
| `lean` | `swing` when the absolute margin is 5.0 or less, otherwise `blue` (Democratic) or `red` (Republican). |

### data/senate_delegation.csv

The two senators serving the day before each general election.

| Column | Meaning |
| --- | --- |
| `state` | State. |
| `year` | Election year. |
| `election_date` | General election day for `year`. |
| `senator1`, `senator2` | The two senators on that date. |
| `senator1_party`, `senator2_party` | Their parties, with independents as the party they caucus with. |
| `lean` | `red` when both are Republican, `blue` when both are Democratic, otherwise `purple`. |

## data/answers/ (generated by analyze.py)

Each file is the result of one SQL select, or a regression, over the tables above.

### data/answers/seat_change_2026.csv

Question 1. Each 2026 race beside the prior election for its seat. A change is empty when either election lacks that party.

| Column | Meaning |
| --- | --- |
| `year`, `state`, `office`, `seat`, `special` | Shared keys for the 2026 race. |
| `prior_year`, `prior_special` | Year and special flag of the prior election for the seat. |
| `prior_dem_candidate`, `dem_candidate` | Democratic candidate then and now. |
| `prior_gop_candidate`, `gop_candidate` | Republican candidate then and now. |
| `prior_dem_pct`, `dem_pct`, `dem_pct_change` | Democratic share of all votes then, now, and the change. |
| `prior_gop_pct`, `gop_pct`, `gop_pct_change` | Republican share of all votes then, now, and the change. |
| `prior_margin`, `margin`, `margin_change` | Democratic minus Republican share of the two party vote then, now, and the change. |
| `same_dem_candidate`, `same_gop_candidate` | True when the last name matches the prior candidate's. |
| `incumbent_party`, `incumbent_running` | Incumbency of the 2026 race. |
| `comparable` | True when the race can be compared with its prior (a prior exists, both parties have votes in both elections, and the race is not the first House election on a census map). |
| `redrawn` | True when 2026 is the first election on a new map. |
| `official` | True when the 2026 count is certified. False while counts are partial or unofficial. |

### data/answers/seat_change_2026_by_lean.csv

Question 1, grouped by presidential lean. Non comparable races keep their rows so each group can count what it leaves out.

| Column | Meaning |
| --- | --- |
| `presidential_lean` | State lean for the race year (`red`, `blue`, or `swing`). |
| `president_year` | Presidential election that lean comes from. |
| `lean_margin` | Margin of that election, in points. |
| `prior_year` | Year of the prior election for the seat. |
| `prior_margin`, `margin`, `margin_change` | Two party margin then, now, and the change. |
| `comparable`, `redrawn`, `official` | As in `seat_change_2026.csv`. |

### data/answers/incumbency_presidential_lean.csv

Question 2. The incumbency bonus: how much better the incumbent's party does than in an open seat, by office and lean group.

| Column | Meaning |
| --- | --- |
| `office` | `house`, `senate`, or `governor`. |
| `lean` | Presidential lean group: `red`, `blue`, or `swing`. |
| `year_scope` | `pooled` for 2014 to 2026 with year effects, or a single election year fitted alone. |
| `incumbent_party` | `DEM` or `REP` for that party's incumbents, or `ALL` for both signed together. |
| `regression_bonus` | Incumbency bonus from the regression, in points of two party share for the incumbent's party. Empty below the minimum seat count. |
| `cross_check_bonus` | A check on the regression: mean change in the incumbent party's two party share where its incumbent ran, minus the mean where the seat was open. |
| `seats` | Seats held by incumbents of that party in the scope. |
| `races` | Races in the scope. |
| `wald_diff` | Democratic bonus minus Republican bonus. |
| `wald_se` | Standard error of that difference. |
| `wald_p` | p value of the Wald test that the two bonuses are equal. |

### data/answers/turnout_k.csv

Question 3. Could turnout alone, with no voter changing sides, explain each shift? Rows are comparable races from 2014 on.

| Column | Meaning |
| --- | --- |
| `year`, `state`, `office`, `seat`, `special`, `prior_year` | Shared keys and prior election year. |
| `a` | Democratic votes now divided by Democratic votes then. |
| `b` | Republican votes now divided by Republican votes then. |
| `k` | `a / b`, how many times more Democratic voters turned out than Republican voters. 1 means no shift. |
| `flip_share` | Change in Democratic two party share. It is the share of the prior electorate that would switch sides at fixed turnout. |
| `redrawn` | True when the race is on a new map. |
| `d0`, `r0` | Prior Democratic and Republican votes. |
| `d1`, `r1` | Current Democratic and Republican votes. |
| `k_effective` | Democratic count needed to give the current share, divided by `d0`. Equals `k`. |
| `required_extra_dem_votes` | Democratic ballots that turnout alone must add (positive) or remove (negative). |
| `actual_total_votes_change` | Change in votes cast in the race. |
| `actual_statewide_ballots_change` | Change in statewide ballots, from `turnout.csv`. |
| `actual_statewide_vep_turnout_change` | Change in statewide turnout rate, in points. |
| `comparison_change` | Race level change in votes used for the check. For a redrawn race it is the statewide change scaled by the prior race's share of statewide ballots. |
| `slack` | Allowance of 2 percent of `d0 + r0` for ballots moving between the top two candidates and others. |
| `turnout_plausible` | True when the required change fits within `comparison_change` plus `slack`. Empty when `comparison_change` is. |

### data/answers/dummymander.csv

Question 4. Did mid cycle redistricting hurt incumbents? House incumbents in states with a new mid cycle map form the `redrawn` group, and those elsewhere form `not_redrawn`.

| Column | Meaning |
| --- | --- |
| `year` | Election year with at least one mid cycle map first used. |
| `office` | Always `house`. |
| `group` | `redrawn` or `not_redrawn`. |
| `mean_change` | Mean change in the incumbent party's two party share against the prior election, in points. |
| `difference` | `redrawn` mean minus `not_redrawn` mean, repeated on both rows. |
| `races` | Races in the group. 0 when the group has none. |

## Candidate names

Every candidate name in `data/overrides/result_overrides.csv` and the generated CSVs in `data/` is normalized by `lib/names.py`, so one person has one spelling across MEDSL, AP, Wikipedia, and the overrides.

- A name written in capitals is lowered to mixed case, with `Mc` and `O'` prefixes capitalized, as in `Bob McDermott` and `Beto O'Rourke`. A mixed case name keeps its capitals.
- `LAST, FIRST` becomes `First Last`. A suffix after a comma is not a last name, so `ANGUS S. KING, JR.` becomes `Angus S. King Jr.`.
- A bare initial gets a period (`Ethan A. Berkowitz`), and `Jr.` and `Sr.` take a period.
- Nicknames sit in straight double quotes, and mangled curly quotes and backslashes from MEDSL are repaired.
- Rows that differ only by spelling are merged into one candidate, with their votes summed.
- The bucket for unnamed candidates is `Other`.
